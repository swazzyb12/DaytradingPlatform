# Paper Market

A local learning terminal for Gate.io public futures and options data with a persistent paper account. The app never places, amends, or cancels Gate orders and does not require Gate API keys.

## Start Locally

Prerequisites: Node.js 20.10+ and npm. Newer Node 20 LTS is recommended to avoid dependency engine warnings.

```sh
npm install
npm --prefix backend install
npm --prefix frontend install
npm run dev
```

Open `http://localhost:5173`. The Fastify API listens on `http://localhost:3001`; Vite proxies `/api` and its WebSocket connection to the API. The paper account is stored in `backend/data/paper-trading.sqlite` by default. Set `PAPER_DB_PATH` to change it; set `PORT` to change the API port.

## Available Workflows

- **Perpetuals:** Gate USDT contract catalogue and REST book bootstrap; public Futures WebSocket ticker, depth updates, and trades; enter market/limit size as either USDT order value or USDT margin. Margin input is multiplied by selected leverage, then converted to a valid contract quantity using reference price, multiplier, and size step. Limit price remains a separate price-per-contract input. Includes partial fills, configurable fees/slippage, position PnL, and scheduled funding debits/credits.
- **Isolated risk baseline:** Fetches public Gate USDT risk tiers, snapshots per-position leverage/initial margin, estimates cumulative tier maintenance and liquidation price, and blocks exposure increases when risk metadata is missing or stale. Mark-triggered simulated liquidation cancels open contract orders, walks visible depth, records modeled fees/slippage, and flags any residual. Risk values identify formula version and mark/tier freshness.
- **Delivery:** Gate USDT direct (linear) dated contracts only. Supports USDT order-value or margin sizing with the same leverage conversion as perpetuals. Contracts, book, and trades use public REST polling every two seconds. Gate-reported expiry price and fee are used for settlement when present. Inverse contracts are excluded because their PnL model differs. Delivery does not receive perpetual funding.
- **Options:** Gate-listed calls and puts, expiry/strike selection, contract multiplier, IV/Greeks, public order book, and REST polling. The order ticket remains quantity-in-contracts. Zero exchange marks are displayed as unavailable; estimates use the executable side of the visible book instead. Expiry settlement uses Gate's public per-contract profit and fee response when it is available. Opening short options is blocked until exchange-specific collateral rules are modeled; selling to reduce an existing long is allowed.
- **Paper account:** Starting balance, leverage setting, fee assumptions, extra taker slippage, positions, open/recent orders, fills, and append-only ledger. Reset clears the local account and restores the starting balance.

## Verification

```sh
npm run build
npm test
npm --prefix frontend run lint
```

The backend tests cover book deltas, price/size validation, stale-feed rejection, depth-walk fills, limit fills, fees/slippage, partial closes, cross-contract margin, signed sell trades, long/short funding, option/delivery expiry accounting, Gate tier maintenance examples, risk-data validation, leverage snapshots, and simulated liquidation edge cases.

## Simulation Boundaries

- A public order book does not expose queue position. Market orders walk visible depth; resting limits fill conservatively on qualifying public trades. Results are estimates, not Gate fills.
- Futures funding uses the latest Gate rate and next-funding timestamp observed by the app. It is applied once at the scheduled timestamp using the last observed mark; a disconnected client cannot reconstruct unseen intermediate market states.
- Margin availability is an educational estimate. The isolated USDT linear model uses Gate public tier rates/deductions and a modeled exit/liquidation fee; it does not reproduce Gate's complete liquidation engine, insurance/ADL, risk-table fallback, hedge mode, or cross-margin behavior. Near-maintenance warnings currently use a fixed 110% threshold.
- Options are REST-polled because no public Options WebSocket channel was found in Gate's maintained `gatews` SDK. Some contracts have no mark/last trade; those remain unmarked until Gate publishes a usable quote/settlement value.
- Delivery is REST-polled because the maintained SDK did not expose a verified delivery WebSocket channel. The adapter intentionally supports direct USDT delivery contracts only.
- Historical replay, charting, stop/trigger orders, hedge mode, and cross-margin simulation are not included yet.

## Architecture

- `frontend/`: React + TypeScript + Vite trading workspace.
- `backend/`: Fastify API, Gate public market-data adapter, paper simulation, and SQLite persistence.
- `backend/src/market-mapping.md`: Gate public REST/WebSocket mapping and source notes.
- `IMPLEMENTATION_PLAN.md`: staged roadmap and acceptance checks.

Only public market-data APIs are called. Keep the app private to your machine/network; paper balances and simulated performance are not real funds or investment results.
