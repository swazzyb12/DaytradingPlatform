# Gate Market-Data Mapping

| Product | REST source | Public WebSocket | Paper-specific behavior |
| --- | --- | --- | --- |
| USDT perpetual | `/futures/usdt/contracts`, `/futures/usdt/contracts/{contract}`, `/futures/usdt/order_book` | `wss://fx-ws.gateio.ws/v4/ws/usdt`; `futures.book_ticker`, `futures.trades`, `futures.order_book_update`, `futures.tickers` | Uses exchange mark/funding fields when present; fills are local estimates |
| USDT delivery | `/delivery/usdt/contracts`, `/delivery/usdt/contracts/{contract}`, `/delivery/usdt/order_book` | Futures-style stream is not enabled until its settlement conventions are verified | No perpetual funding |
| Options | `/options/underlyings`, `/options/contracts`, `/options/tickers`, `/options/order_book` | No Options WebSocket channel was found in Gate's published `gatews` SDK/docs at implementation time | Market data refreshes by REST; premium and expiry settlement rules require contract-level verification |

The Futures WebSocket URL and channel names are from Gate's maintained [`gatews` SDK](https://github.com/gate/gatews). The current Futures adapter accepts a local depth update only when its update IDs continue from the current depth; otherwise it reloads the REST snapshot and reconnects. Options stay on public REST polling until Gate publishes a verified Options socket specification. No private or authenticated exchange endpoint is used.
